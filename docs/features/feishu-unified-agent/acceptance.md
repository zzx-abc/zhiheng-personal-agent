## 场景覆盖

| 场景 | 实际结果 |
| --- | --- |
| A 群推送与回复 | 替身发送保留平台ID与多消息映射；回复定位、同条件阶段比较通过，群不调用模型/资料检索 |
| B 私聊查询E编号 | 直接读原事件快照通过，无需复制群聊天 |
| C 结合本人资料 | 复用检索/引用校验，市场证据与资料分析分区；保留来源版本，通过 |
| D 群私人请求 | 只返回本人绑定的30分钟H码；未声称主动私聊成功；过期/陌生用户拒绝，通过 |
| E 收藏 | 同事件重复收藏只保留一条；批注保存；未新增/启用任务，通过 |
| F 暂停 | 唯一完整任务名/ID可暂停；主题名不会误停整项任务，通过 |
| G 模糊指代 | 只用显式编号和本会话映射；多个/未知目标提示少量授权候选，通过 |
| H 越权 | 应用/租户/用户/场景/目的地检查及发送前撤权检查，通过 |
| I 正常聊天 | 模型替身返回会话回答，不创建资料或监控；至多3轮同范围会话，其他话题不拼入，通过 |
| 资料纠正/删除 | 旧派生回复失效，独立市场事件保留，通过 |
| 幂等/恢复 | 事件和消息双去重、不同租户命名空间、持久outbox重复收集不重复，通过 |
| 迁移/回滚 | 活跃worker、待发/发送中/unknown阻止切换；版本竞争拒绝；保留已发记录，切点不重放历史，通过 |
| 通道变更 | 事件+逻辑目标账本不随物理渠道/receipt变化；未知不自动重发/换渠道，通过 |
| 运行隔离 | 模拟PDF持续等待时雷达仍执行；同槽不并发；既有真实worker启动测试通过 |

## 未验证与限制

1. 新应用群发送、群@事件与私聊跨场景真实端到端尚未验收；需要可信群/租户绑定、控制台权限发布核对及明确授权的测试目标。
2. 本轮没有付费Kimi效果测试；引用与权限路径通过替身验证，不等于模型语义质量已实测。
3. 没有卡片操作回调或主动私聊，使用受控文字命令/本人交接码。不会更新群卡片为私人答案。
4. 旧Webhook没有平台消息映射，不能用新应用编辑旧消息；旧无条件标识的事件不进行未经证实的“同条件上次”比较。
5. 群参与者当前只有配置的本人可以调用工具；不是多人群知识助手。陌生人静默忽略。
6. 并发是本机同进程有界异步执行，未做CPU压力/大规模容量测试；休眠或离线不提供持续在线保证。
7. 出站uuid的当前有效期和跨接口范围未得到足够官方可读依据，不依赖其做自动重发；发件箱保留unknown等待人工核对。
8. 私人周报/任务摘要在统一入口开启后留在本机，不自动迁到未验证私聊，也不继续发雷达群。价格与行情事件推送仍沿用既有启用/到期条件。
