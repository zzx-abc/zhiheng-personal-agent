# 多主题雷达实施进度

## 实际查明
旧版只接受十个中证一级行业ID，按代码等距抽样；不能配置指定证券。3/5日指标混入当前盘中价格；新版本将完整交易日与当日变化分开。质量检查同时依赖报价、日K、量字段，导致已知价格难以展示；整个分类缺失会拦截其他组。首次基线已有状态但只展示非watching候选，缺少所有核心对象体检。次日基线重建、配置版本及outbox可复用。

## 计划
1. 版本化主题库、证券业务证据、任务引用；首批三个主题。
2. 同一采集批次去重，固定完整日窗口、独立报价质量、动态条件与主题/个股分层结果。
3. 持久状态和事件去重、主动体检、UI配置/来源/回放。
4. 隔离程序与浏览器测试、真实数据预览；更新版本和GitHub。
5. 按用户明确授权将现有任务升级并启用，交易时段每30分钟；验证worker调度。

## 决定与未完成
使用现有SQLite、worker、行情缓存和飞书outbox，不增加模型调用。历史个人价位因除权口径未验证先保留但不触发。腾讯无正式最终收盘标志，不承诺当日收盘确认；完整历史窗口保守截止前一交易日。官方业务来源逐项核实中。当前尚未实现/启用多主题版。

## 限制
真实飞书入站仍属于上一个记录功能的未配置依赖；雷达使用既有群Webhook推送通道。自动主题提醒尚无真实市场触发事件可验收，不发送虚构测试信号；沿用既有发送机制并用隔离状态测试验证去重。2027交易日历、正式收盘标志、可比分钟量、宇树行情覆盖和自动公告跟进未完成。保持Mac清醒和启动进程运行。

## 2026-11-14 决策层整改（进行中）
用户任务书要求先改条件与时间语义，再做动作映射和用户摘要。未授权真实群测试、任务启停或更换通知渠道。

已定位：
- relativeMet 将历史3/5日、盘中、量能混为一个三态值；有效FAIL被UNKNOWN覆盖。
- quoteUsable 对盘后仍检查10分钟延迟；relative组合盘后仍需盘中相对，历史窗口始终排除当日。
- priceLines 强制非空validUntil，缺截止日也停用；停用理由混合到期与可比性。
- service 在长时间离线后重置基线；恢复也清除状态。任务配置和主题版本已持久化，但此行为造成不必要初始化。
- 飞书R详情固定前4核心股且无策略动作层；应用主动发送text、回复plain_text卡片；Webhook使用text。
- 腾讯适配器明确 finalPrice=false / finalVolume=false，尚无可信最终日线标记；本次不会伪造该能力。

实施顺序：五态原子/组合 + 模式与操作数 → 可配置、默认停用的策略草稿 + 双序列排序 → 共用确定性摘要/详情/诊断 → 固定隔离样本、回归与移动端验证 → 文档、版本和Git。当前尚未完成验证。
