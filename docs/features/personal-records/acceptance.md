## 用户验收顺序
1. 在资料入口上传一份可公开的文本PDF并说明一个疑问，检查原件、物理页和缺失页。
2. 重复上传同文件、写不同批注，检查两个收录行为都有记录，文件不重复解析。
3. 纠正收藏目的为方法学习，用旧立场/新疑问搜索并比较当前与历史。
4. 删除一条记录，确认检索、问答和待办失效，共享原件仍保留给另一条。
5. 自建飞书应用配置完成后，先只授权本人/指定会话，再测试文件、回复纠正、查找和删除确认。配置步骤见implementation.md。
